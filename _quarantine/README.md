# `_quarantine/` · 隔离区

本目录存放**已废弃、但本机仍需溯源**的文档与素材。它们与当前代码不符。

**本目录内容不得随仓库分发、不得随安装包分发、不得对外提供。**
本目录唯一的版本库成员是本说明文件；其余内容由 `.gitignore` 排除
（规则：`_quarantine/*` + `!_quarantine/README.md`）。

---

## 1. 为什么隔离，而不是删除

| 理由 | 说明 |
|---|---|
| 溯源 | 当前 `docs/` 体系的结论是从这些旧文档提炼出来的，出争议时要能回到原文 |
| 可逆 | 隔离只是换位置，恢复成本为零；删除不可逆 |
| 边界清晰 | 放在 `04_文档/` 时，它与「当前版文档」混在同一层目录，容易被误当现状引用 |

## 2. 隔离规则

1. 进入本目录的文件，**文首必须加**「已废弃（日期）—— 见 xxx」标注块，写清废弃原因与现行替代文档。
2. 正文**不改写、不删减、不补数字**。历史轴数字与结论就地冻结。
3. 本目录**只增不减**；确需删除时先确认 `docs/reference/reference-conclusions.md` 或仓库外冷备中已有等价留存。
4. 任何「据此施工」的行为都是错误用法：正文里的路径、命名、参数一律按当时状态理解。

## 3. 恢复条件

同时满足下列三条才可移出：

1. 内容已按当前实现逐条复核，与源码一致；
2. 该主题在 `docs/` 体系内没有 `Active` 文档（否则应并入现有当前版，不另立一篇）；
3. 内容可对外分发，无额外限制。
