## 3. 架构一图流

```
OBS Studio 32.1.1
└─ 视频源（摄像头 / 采集卡）
   └─ 滤镜链
      └─ obs-beauty.dll  ·  obs_beauty_filter
            ├─ YuNet 人脸检测（ONNX Runtime）
            ├─ 肤色掩码 / 区域椭圆 / 5 关键点
            ├─ 保边平滑 + 高低频分离 + 细节回填
            ├─ 色调（美白 / 红润 / 清晰 / 全局锐化 / 脸内锐化）
            ├─ 五官局部（去法令纹 / 去黑眼圈 / 亮眼 / 祛斑痘 / 五官立体）
            └─ 位移场（瘦脸 / 大眼 / 下巴）

obs-beauty-ui.dll  ·  顶层菜单「美颜(&A)」
└─ 参数面板（遍历滤镜 obs_properties 动态生成，不持有参数副本）
   └─ 读写全部走滤镜属性，面板与滤镜同版本号
```

**帧管线**：检测 → 肤色掩码 → 磨皮 → 色调 → 锐化 → 五官局部 → 美形（管线最末端）→ 输出。
全 0 参数时逐字节透传，不进引擎。

## 5. 构建

在 `02_构建\` 下执行：

```bat
build_manual.bat      :: 编译 obs-beauty.dll（滤镜 / CoreEngine）
build-ui_320.bat      :: 编译 obs-beauty-ui.dll（面板）
```

**输出统一到 `02_构建\build_output\`。**

本设备没有 Rust 工具链，全部走 MSVC 14.51；`vcvars64.bat` 因沙箱拦截 `reg.exe` 不可直接使用，
需手动设置 `INCLUDE` / `LIB` / `PATH`（`build_manual.bat` 内已硬编码）。

构建后自检：

```powershell
& python '02_构建\verify-ui-imports.py' '02_构建\build_output\obs-beauty-ui.dll'
```

## 6. 安装与卸载

`03_装机\install_3.1.39.bat` —— **右键「以管理员身份运行」，且先关掉 OBS**。
流程：查 OBS 是否在跑 → 备份现有两件到 `backup_install_<日期>\` → 先装滤镜再装面板 → 校验 PE 体积。

> **代理进程是普通令牌，写不进 `C:\Program Files`**，`Start-Process -Verb RunAs` 会被安全策略拦掉。
> 装机必须手动提权。`C:\ProgramData` 可写（面板装那里免提权）。

**目录名必须与 DLL 名完全一致**：OBS 扫描规则是 `<目录名>/bin/64bit/<目录名>.dll`，
名字对不上会**静默跳过且不写日志** —— 表现就是「像没装」。

卸载：`03_装机\OBS美颜插件卸载.bat`。回滚件在 `03_装机\backup_install_20261030\`。

**装完自查**：两个 DLL md5 == §2 表 → 日志有 `init OK (v3.1.39, engine=core/1.4.0, region=on(every=0)…)`
→ 日志有 `faces=1` 且无 `core engine has NO face mask` 警告 → 面板左下角显示 `v3.1.39` 且无「（面板 x.x.x）」括注。

## 7. 两个入口

| 入口 | 位置 | 说明 |
|---|---|---|
| **滤镜** | OBS 源 →「滤镜」→ 加「OBS美颜」 | id `obs_beauty_filter` |
| **面板** | OBS 顶层菜单栏右侧「美颜(&A)」 | Dock 形式、可拖动、窗口尺寸记忆（`ui.ini`） |

面板**不硬编码参数表**，遍历滤镜的 `obs_properties` 动态建控件；滤镜那边改参数，面板自动跟随。
面板与滤镜同版本号，面板左下角显示滤镜实机版本，对不上时加括注标出（= 安装漏换的现场证据）。

14 项功能分五页：**美颜**（磨皮/肤色/档位）/ **锐化** / **五官**（去法令纹/去黑眼圈/亮眼/祛斑痘/五官立体）/ **美形**（瘦脸/大眼/下巴）/ **高级**。

## 8. 性能与画质基线

| 项 | 值 |
|---|---|
| 1080p 纯磨皮 | **6.43 ms** |
| 含检测帧（异步后） | **≈18.6 ms**（异步前最慢 22.90 ms） |
| 1080p 30fps 均摊 | **9.48 ms / 33 ms 预算**（余量 3.5 倍） |
| 画质复刻度 | **79.0 分**（8 个计分项均分；保守口径 70.2） |
| 功能覆盖 | SDK 功能全集 14 项，**14 / 14** |

> 数字出处：`05_验证\goldens\masks\bench_tone.md`（1080p 纯磨皮 6.43 / 含检测 18.63 / 均摊 9.48）。
> `C1_CPU性能优化.md` 里的 7.25 ms 是更早版本的引擎层口径，两者不可混用。

单项最高全局锐化 91.3（corr 0.987）；最低去法令纹 65.0（小信号项，改动量已对齐 4.7%，扣分来自 RMSE 口径）。
