## 1. 结论先行

色调与细节层是**独立于磨皮的主动处理**，不要把它当成「别把细节磨掉」的被动保护。

- **美白**：对数曲线 + 保色相；**红润**：提红压绿；用查表避开逐像素 `log`。
  **作用范围是整帧**（`1.0.2.0` 起，不乘皮肤掩码，与 GPU 版 / 参考实现同口径）；处理顺序有约束，改顺序会改变结果（具体顺序见 `c06` 归档件，本文未逐字复核，待人工确认）。
- **clarity 是主动增强中频对比**，不是「保护立体感」。原设想「被动保护细节就能拉开立体感差距」
  被开工前的零成本标定推翻；立体感差距靠 clarity 主动增强（`c09`、`c03`）。
- **锐化走频率分离**：高频层从**原图**取，不是对磨完的图做 unsharp（`c11`）。
- 磨皮为 0 时**脸内锐化无效、全局锐化仍生效**（`c11`）——这与 `README.md` §8 第 4 项
  「磨皮=0 时锐化滑块无效」的历史遗留是同一现象，**是否仍存在待人工确认**。

## 1.1 色调三段的施加范围（`1.0.2.0` 起：整帧）

**为什么改**：手往脸上一搭，手背上会出现一块形状跟着脸框走的美白区。根因不在肤色判据
（手背就是肤色，YCbCr 必然放行），而在「LUT 结果 × 掩码」这个写法本身：掩码的边界
（椭圆 / 脸框裁切 / 脖子矩形）在画面上被乘成一条**可见色界**，色界恰好切在手背上。

**改法**：`beauty_freq.cpp` 的 `toneColor()` 默认整帧施加（不看 mask、不看 roi），
与 GPU 版 / 参考实现同口径 —— 参考实现的美白是纯 3D-LUT，不读 `tex_mask`。
`BEAUTY_TONE_GLOBAL=0` 回到「只在 roi 内、mask>0」的旧行为，**逐字节**一致。
磨皮 / 锐化 / 五官不动：那几项要的是「只动皮肤」，色调要的是「整幅一致的色彩」。

| 事实 | 结论（数字见 `05_验证/tone_global_20261108.md`，非 Active 文档） |
|---|---|
| 判据：箱内 σ（按输入灰阶分箱后 Δ 的离散度） | 旧口径有非零离散（掩码在调制 Δ）→ 新口径**归零**：Δ 只由颜色决定 |
| 判据：掩码外是否被改动 | 旧口径**一个像素都不改** → 新口径掩码外照样改，掩码边界不再是色界 |
| 与参考实现比对 | 真值帧 `out_white_on/off` 的差值 bbox（含头发 / 衣服 / 背景）与本工程新口径**完全一致** |
| 代价 | 整帧跑的像素更多（单像素因表预展开反而更便宜）；画面背景随整幅一起被轻微提亮（参考实现亦然） |
| 取证 | `05_验证/tone_global_20261108.md`、台架 `05_验证/_tone_global_probe/`（`build_probes.ps1` 可复现） |

⚠️ 这条**只在台架 + 真机帧上取过证**：真机 OBS 出图与手遮脸的观感仍待人工确认。

## 2. clarity（`c09`）

- 机制：中频对比的主动增强，窗口与上限分别由 `BEAUTY_CLARITY_R`、`BEAUTY_CLARITY_MAX` 控制
  （源码 `beauty_core.cpp` 初始化段逐字核实；另有 `BEAUTY_CLARITY_LEGACY` 可回旧实现）。
- **软膝定标坑**（`c09`）：软膝参数必须在同一套素材上重新定标，拿历史轴的标定值套当前轴会得到
  看似合理但方向错误的曲线；具体做法见归档件。
- ⚠️ 命名陷阱：`c09` 引用的 `D1` 的 `S1` 是**技术线路步骤编号**，不是
  `docs/archive/ab-mask-20261106.md`（`Deprecated`） 的对拍文档编号；归档件为 `docs/archive/tech-roadmap-20261106.md`（`Deprecated`）。

## 3. 锐化与运动自适应 EMA（`c11`）

- 频率分离式锐化：高频层从**原图**取；对磨完的图做 unsharp 会把磨皮引入的台阶一起放大。
- **亮度平面运动自适应 EMA**（`c11` §6.1）：平滑的是**输入亮度平面、不是输出**，
  因此 β=1 时与不做 EMA 逐字节等价，回退是安全的。
- `c11` §5 三个「看起来不对但不是 bug」的读数解释：锐化量、曲线读数、分区统计各自口径不同，
  照单看会误判成回归；具体解释见归档件。
- 细节回填的两个离线标定开关（源码注释登记）：`BEAUTY_DETAIL_THR`（细频带软阈值 / 削噪量）、
  `BEAUTY_DETAIL_MID`（中频带基准增益）；**只在离线标定用**，不要当面板参数。
