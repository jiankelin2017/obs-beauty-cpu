## 1. 结论先行

- **「指标改善」不等于「观感改善」**（`c17` §5.5）：这类优化**无法用看画面做 A/B**，
  必须靠离线指标；反过来，指标动了也不代表用户能看出来。
- **所有基于 `face_src` 的离线结论不可外推到真机**（`c19`）：离线素材是单张脸的裁剪，
  真机的白平衡、机位、脸宽都不同。
- **口径纪律**：不同统计区域的读数**不矛盾但不可混用**，见 §2。
- **证伪链终点**：「真机磨皮不足」的最终根因是肤色椭圆中心不随白平衡自适应，
  `c19` 的中间根因已被 `c20` 推翻；落地见 `docs/design/design-face-mask.md`。

## 2. 口径纪律（读任何历史数字之前先看）

- `c14` §4 与 `ab-metric`：**全掩码平均**会被大量非皮肤像素稀释，**分区细纹理频带**才回答「核够不够强」；
  两套读数不矛盾，但**绝对不可混用、不可相减**。
- `ab-metric`：「ROI 全区域」读数受块均值稀释，只能回答整体观感，不能回答核够不够强；
  旧比较区域里过半的「差异」来自白蕾丝上衣和背景衣架，**不是皮肤**。
- `ab-metric` 自述样本量只够判断方向、不够精调参数；`ab-mask` 的有效场景全是同一张脸的扰动。
- `c08`：「小幅度高频保留%」指标本身不可靠，应用「脸颊台阶像素占比」替代，
  见 `docs/design/design-smoothing.md` §3。
- `ab-smooth`：离线基准 DLL `blur_type=1` 的输出**不是产品真值**，两套口径不可混用；
  曲线 RMSE 是「曲线拟合」而非「结构同一性」。

## 3. 证伪链（按时间顺序，只看结论）

1. **`c14` §5 五条假设全部被证伪**：`freqMagHi` 天花板 / 五官保护挡住唇纹 /
   掩码没盖到额头 / 加大迭代次数 / 羽化削弱——都不是差距来源。
2. **`c16`**：默认档位下**痘印不是差距来源**；用户看到的「痘印没了」更可能是第三方开了祛斑痘，
   真正该动的是**祛斑痘默认值**（面板默认 0）。
   方法论必须保留：**没有因变量就测不了、100% 保留也算假通过**（合成阳性样本的用处是证明指标有响应）。
3. **`c17`**：**「档位→尺度联动」假设错误**，加大低通尺度反而更差；真正主导的是幅度门控上限
   `freqMagHi`（环境变量 `BEAUTY_FREQ_MAG`）。§5.5「指标改善 ≠ 观感改善」是本组最重要的结论；
   §6「阴影频带双尺度缺口」属**新功能、未实施**。
4. **`c18`**：核尺度是**绝对像素常量、不随脸宽缩放**，固定值换分辨率 / 机位即失效；
   §5 可比性风险（`NamaGoldenRun`（历史轴离线脚本，非插件源码符号）后四参数、真机第三方默认配置未知）**这条从未核实**。
   放大图上看到的「变细」是**插值假象**，`c19` 已用真实素材修正。
5. **`c19`**：曾把真机磨皮不足归因于「核尺度不随脸宽缩放」——
   ⚠️ **已被 `c20` 推翻，不得据此施工**。仍有效的是它的方法论：
   `face_src` 离线结论不可外推、真机 0 档帧可作离线对拍输入（core 全 0 时逐字节透传）、
   不同时刻抓拍的截图信噪比不足、无法定量。
6. **`c20` → `c21`**：最终根因是肤色椭圆中心写死、不随摄像头白平衡自适应，
   解释了 `c17`「削过头」与 `c19`「削不够」为何方向翻转；已落地 `estimateSkinCenter()`。
   `c20` §5「候选修法」由 `c21` 落地，§7「下一步建议」属过程记录。
   `c18` §4「核尺度随脸宽自适应」的落地方向**未被采纳**。

> **引用规则**：`c19` 的根因段落只能作为「曾被推翻的中间结论」引用；
> 任何施工、调参、复现实验都必须以 `c20` / `c21` 与 `docs/design/design-face-mask.md` 为准。

## 4. 仍然有效的局限与坑

- `c20` 四条局限：单帧单摄像头、掩码占比是反推值、**掩码修好 ≠ 削对频段**、偏色并不极端。
- `c21` 三项遗留（未在当前轴复核）：高档位细纹理矫枉过正、阴影频带双尺度缺口、高档位耗时。
- `c14` §6「未实施候选」、`c20` §7「下一步建议」、`c17` §5「建议改动」**均属过程记录**，
  且 `c17` 的建议已被 `c20` / `c21` 路线取代。
- 应急调参口径：只调 `BEAUTY_BLUR_SAT`，不动核参数（`c21`）；不要动 `freqMagHi` 追强度（`c15`）。
