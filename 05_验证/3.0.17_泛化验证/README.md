# 3.0.17 泛化 / 抗噪验证 — 原始记录

**一句话结论**：算法**抗噪**（±5→±15 收益反而更强，±30 才失效）；换素材那次"失败"
是 **fuai 肤色掩码错位**造成的，不是算法问题，但它暴露了一个更值钱的缺口——掩码没有自检。

运行环境：完整夹具在 `C:\nama_e2e`（本目录只是快照，脚本里路径都指向那里）。
测试 DLL：`nama_engine_test_317.dll`（生产源码 + 测量钩子 + `NamaSeqTest`）。
统一参数：磨皮 50 / 锐化 50，10 帧，四指标（平坦高频↓好 / 边缘对比↑好 / 总细节 / 闪动↓好）。

## 1. 抗噪实验（素材 A，掩码已确认对齐）

底图 `out/frame_0.png`（1074×604），每帧加均匀噪声，脚本 `noise_test.py`：

| 噪声 | 平坦高频 | 边缘对比 | 总细节 | 闪动 |
|---|---|---|---|---|
| ±5（原 nz_in） | 1.767 → **1.470（−16.8%）** | +16.5% | +13.1% | −3.8% |
| ±15 | 6.187 → **4.639（−25.0%）** | +17.1% | +0.8% | **−11.5%** |
| ±30 | 12.475 → **14.211（+13.9%）** | +16.4% | +2.2% | +11.6% |

读法：
- **±15 这一档的平坦本底（6.187）与素材 B（6.43~6.82）几乎相同，效果却是所有档里最好的**
  ——所以"素材噪声大"不能解释 B 的失败。
- ±30 才真失效：`flat` 集合从 23041 px 掉到 13023 px，"结构"判据被噪声占满，
  平坦抑制无从下手，只剩 `texEdge` 增强 → 平坦区更毛、闪动也升。

## 2. 换素材实验（素材 B，640×394，来自 `face_src.png`）

| 组 | 平坦高频 | 边缘对比 | 总细节 | 闪动 | 脸内被改动像素 |
|---|---|---|---|---|---|
| B 640×394 | 6.818 → 7.567（+11.0%） | +6.8% | +0.8% | +2.1% | 19.3% |
| B 2× 1280×788 | 2.073 → 2.239（+8.0%） | +3.4% | +0.3% | +0.7% | 7.6% |

"只改动 19% 的脸内像素"是异常信号 → 把掩码叠回画面，看到：

- `chk_mask_bx.png`：绿线是一根**窄竖条**，压在右半脸 + 头发 + 胸口，没盖住整张脸；
- `chk_mask_B_frame10.png`：同一序列第 10 帧，这根带子又**飘到左侧**、盖在头发和背景上；
- `chk_mask_A.png`（对照）：素材 A 的掩码严丝合缝——额头→脸颊→下颌→颈部，停在下巴领口。

⇒ 掩码错位时 `mv≈0` → `am≈0` → 四档全打空。**这次失败不能用来判定算法好坏。**

## 3. 排查过程中发现并修掉的夹具 bug

`nz_probe_dlldir.run()` 原来这样取掩码：

```python
dumps = sorted(f for f in os.listdir(HERE) if f.startswith("mask_dump_"))
src = os.path.join(HERE, dumps[-1])          # ← 按文件名取最后一个
```

而 `clear_dump()` 早前被改成空操作（避开沙箱删除计数），目录里残留着上一次 60 帧运行的
`mask_dump_059.raw`，于是被判成"本次掩码"。第一次跑 B 时拿到的其实是**素材 A 的掩码**
（两份 md5 都是 `c4bf880da1a2db79396245a26d8907b1`，见 `chk_grid_three.png` 左右两张完全一致），
flat/edge 划分全错，得出过一个假的 "+4.01%"。

修法（已合入 `nz_probe_dlldir.py`）：按 mtime 取本次 run 写出的最后一个转储。

```python
_t0 = time.time()                                   # WinDLL 加载之前
...
dumps = [f for f in dumps
         if os.path.getmtime(os.path.join(HERE, f)) >= _t0 - 1.0]
dumps.sort(key=lambda f: os.path.getmtime(os.path.join(HERE, f)))
```

修好后 B 640 的掩码 md5 是 `301d27dcf7695b73359108c9439ba9c0`（`mask_bx_m0.raw`），
本文第 2 节那张表就是修后的数字。

## 4. 留给下一棒的活

| 优先级 | 事项 |
|---|---|
| **P0** | 掩码自检兜底：覆盖率 + 与上帧重合度做廉价判据，异常时退回整脸/整帧，而不是拿错位掩码硬磨 |
| P1 | 1080p 实拍复核 `kTexLo` / `kTexHi`（离线只覆盖 1074×604 + 均匀噪声） |
| P2 | `kTexLo/kTexHi` 噪声自适应（用脸内 `\|h_mid\|` 中位数当噪声底），±30 失效就是它 |

另外：`grid_tex.py` 里的 `NAMA_TEX_BASE/FLAT/EDGE` 覆盖在当前测试副本里**已不存在**
（二进制里 grep 不到），直接重跑不会产生差异，要复现网格需先加回 `getenv_s`。
