# 磨皮滑杆曲线对拍 · 2026-10-30 03:30

## 起因

用户贴了 10 张截图（SDK 0/25/50/75/100 + 自制 0/25/50/75/100），要求对比两者的「档位 → 效果」曲线。
结论先说：**截图能定性、不能定量**；定量改用同一张真机原始帧离线同进程跑，结果是**曲线形状反了 + 75–100 死区**。

## 为什么截图不能定量（三条硬理由）

1. **构图不同**：SDK 那组人脸明显更近（源被放大），自制那组是原始 FOV。像素级指标不可跨组比。
2. **不是同一帧**：以各自 0 档为参照做 ECC 对齐后，SDK 25 档的肤色区平均 |Δ| 已达 **12.07**，
   而磨皮本身 0→100 的量级只有 **2 级**（离线实测）。说明这 12 个单位几乎全来自**头部微动 / 曝光变化**，
   真实信号被淹没（自制的 25 档 6.88 同理）。
3. **JPEG**：磨皮改内容 → 量化表分配变化 → 整帧细节跟着动，连背景都被"连坐"（实测背景 detail 随档位单调下降）。

> 定性上用户的观察是对的：SDK 那行逐档明显变柔；自制那行五档肉眼差别很小。这与下面的定量结论方向一致
> （自制 25 档就已经很重、75 档到顶）。

## 定量方法（可复跑）

同一张真机原始帧 `06_离线验证/goldens/real/m00_in.raw`（1920×1080，关滤镜抓的真实摄像头帧），
两套引擎各跑五档，**同进程、同输入、同掩码**：

- 产品：`nama_golden.dll` + 加密 bundle（`C:\btwork\engine`），`blur_type=-1`（= 产品真实行为）
- 自制：`beauty_core_test.dll`，`BEAUTY_SMOOTH_MODEL=surface3`、`BEAUTY_S3_BAND=1`、`BEAUTY_S3_BT=8.3`
- 指标：肤色掩码内 `mean|out − src|`（改动量）、`mean|Laplacian|`（细节保留）

```bat
set GOLDEN_ENGINE_DIR=C:\btwork\engine
python curve_offline.py m00
```

## 结果

| 档位 | 产品改动量 | 自制改动量 | 产品细节保留 | 自制细节保留 |
|---|---|---|---|---|
| 0 | 0.000 | 0.000 | 1.000 | 1.000 |
| 25 | **0.010** | **0.492** | 0.999 | 0.977 |
| 50 | 0.402 | 1.178 | 0.966 | 0.922 |
| 75 | 1.122 | 2.061 | 0.923 | 0.784 |
| 100 | 1.908 | **2.061** | 0.849 | 0.784 |

三条毛病：

1. **低档过强**：25 档我们 0.492、产品 0.010（差 49 倍）。等于"一档就到位"。
2. **高段死区**：自制 75 与 100 的输出 **md5 相同**（`b2f13903f5ca5ed9a8e5655df210004f`），70 档以上画面零变化。
   产品 75→100 还在涨（1.122→1.908）。
3. **曲线形状相反**：产品是**凸**函数（低档几乎不动，高档加速）；我们是起步就陡、随后压平。

另外，实机 0↔100 交替四次验证滑杆本身没问题：肤色区 |Δ| = **3.458 / 3.475 / 3.486**（双向可复现），
亮度稳定在 90.9–91.2（无曝光漂移）→ **实机生效链路正常，问题只在曲线映射**。

## 根因（代码级）

`00_源码/beauty_core.cpp:1123-1129`：

```cpp
// intensity = mix(t·K, 1.0, step(0.7, t))，K = 1/0.7
float I = (tLin >= g_cfg.s3ESat) ? 1.0f : (tLin * g_cfg.s3K);   // s3ESat = 0.7, s3K = 1/0.7
if (I > 1.0f) I = 1.0f;
```

→ `tLin ≥ 0.7` 时 `I` 恒为 1，且 band 路径（`:1146-1160`）里**除 `I`/`e` 之外没有任何随档位变化的量**：
注释 `:1150` 明写 `s3R0/R1/R2、s3Sx/s3Sy、s3YF1/YF2` 在这条路上都不参与，`bp.T` 固定 8.3。
所以曲线只剩 `I` 一条腿，而这条腿在 70 档就到底 → **70–100 逐字节相同**。

产品那边档位同时驱动香农尺度的 σ（`beautyCoreSetFreq(mode, sigma, …)`）与 `I`，所以高档还能继续变柔。
