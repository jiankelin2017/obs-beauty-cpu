# 自研引擎（CoreEngine）集成现状

> 2026-10-28 · 本轮把「开源可商用」边界落地，自研引擎第一次跑通完整链路

---

## 1. 现在的链路

```
obs-beauty.dll
  └─ beauty_core.cpp  CoreEngine（NAMA_ENGINE_IMPL=core 启用）
       ├─ beauty_smooth.cpp   双边滤波（纯 C++，定点 LUT）→ 磨皮
       ├─ beauty_face.cpp     YuNet 检测（自写前处理/解码/NMS）
       ├─ beauty_onnx.cpp     ONNX Runtime 封装（动态加载，不硬依赖）
       └─ 掩码 = YCbCr 肤色 ∩ 人脸框(外扩 1.15)  → 只在掩码内混合
```

实测（face_src 640×394）：

| 项 | 值 |
|---|---|
| 检出人脸 | 1 |
| 掩码覆盖率 | 13498 px = **5.35%** |
| 掩码内磨皮档位曲线误差 | **1.09 个百分点**（r2/σs7） |
| 稳态耗时 | **15 ms** |
| 含检测的那一帧 | 32 ms（掩码每 4 帧重算一次，所以每 4 帧才付一次） |

## 2. 新引入的第三方（全部可商用）

| 组件 | 许可 | 体积 | 备注 |
|---|---|---|---|
| ONNX Runtime 1.20.1 | MIT | 11.6 MB（onnxruntime.dll） | **动态加载**，缺失只降级不崩 |
| YuNet 2023mar | MIT | 232 KB | 固定 640×640 输入、12 个输出 |

`obs-beauty.dll` 的导入表实测只有 `obs.dll` + 系统 DLL，**没有 onnxruntime.dll** ——
用户少装 ORT 时滤镜照常加载，只是自研引擎降级为全帧磨皮。

## 3. 踩到的四个坑（都有价值）

1. **系统里有另一个版本的 onnxruntime.dll**（1.17.1，在 PATH 里）。
   `LoadLibraryA("onnxruntime.dll")` 抓到它，`GetApi(20)` 返回 nullptr，
   表现是「模型加载失败」但看不出原因。
   → 修复：`onnxSetRuntimeDir()` 用**完整路径**加载插件目录下的那个。
2. **路径编码错配**：`GetModuleFileNameA` 返回 ANSI，我按 UTF-8 转成宽字符，
   中文目录直接变乱码，表现为「读不到模型文件」而路径打印出来完全正确。
   → 修复：`acpToWide()` 用 `CP_ACP`。
3. **ORT 在 Windows 只收 `wchar_t` 路径**（`CreateSession`），
   → 改用 `CreateSessionFromArray`（模型读进内存），彻底绕开路径问题。
4. **批处理必须是 CRLF 行尾**：LF-only 的 .bat 被 cmd.exe 解析错乱
   （报 `'source' 不是内部或外部命令` 这种风马牛不相及的错）。

## 4. 还没解决的问题：对拍口径

把掩码接上之后，用原来的口径（比较区域 = SDK 磨皮 100 档的改动区，12.99%）
去算细节保留率，曲线从 `100/90.6/81.1/72.1/63.3` 变成 `100/99.6/99.2/98.8/98.3`，
看起来像「磨皮完全失效」。

**实际原因是口径问题**：我们只磨了 5.35%（肤色 ∩ 人脸框），而 SDK 的改动区是
12.99%（它的皮肤判据更宽，含脖子/肩）。剩下 7.6% 我们根本没动，自然把保留率
拉回接近 100%。掩码本身是正常的（实测 13498 px、faces=1）。

**正确口径**：比较区域应当取「SDK 改动区 ∩ 自研掩码区」的交集。这需要把掩码
导出给对拍脚本（`BeautyCoreMask` 导出），本轮没做。

## 5. 下一步（按优先级）

1. **加 `BeautyCoreMask` 导出**，把对拍口径改成掩码交集，重跑曲线（半小时级）。
2. **扩掩码**：现在只覆盖 5.35%（脸），SDK 是 12.99%。若要对齐老观感，
   要么把「脖子/肩」也纳入（人脸框下方的肤色通道），要么接受「只磨脸」这个
   更保守的行为并单独确认观感。
3. **GPU 化磨皮核**：15 ms @640×394 → 1080p 约 120 ms，CPU 到不了实时。
4. 补真实素材（眼镜/口罩/侧脸/不同肤色）复验。

## 6. 事实与推测

**可验证事实**：检出 1 张脸、掩码 13498 px、稳态 15 ms、曲线误差 1.09 个百分点、
DLL 导入表无 onnxruntime —— 均本机实测，命令见 `06_离线验证/`。

**推测**：1080p 约 120 ms 是按像素数线性外推；GPU 化能到多少没测。
