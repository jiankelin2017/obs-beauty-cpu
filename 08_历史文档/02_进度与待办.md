## 4.1 性能基线（验收实测，满载 = 磨皮80/美白30/锐化80）

| 分辨率 | 耗时 | 折算帧率 |
|---|---|---|
| 640×480 | 18.2 ms | 54.9 fps |
| 1280×720 | 33.8~35.6 ms | 28~30 fps |
| 1920×1080 | 62.9~63.3 ms | 15.8~15.9 fps |
| 1920×1080（全关） | 20.9 ms | 47.8 fps |

线性拟合：`耗时 ≈ 10.7 ms + 24.3 ns/像素`。
**同时开磨皮与锐化是二值跳变**：1080p 下 磨皮0+锐化80 = 22.2 ms，磨皮20+锐化80 = 68.6 ms。
跨版本对照（1080p 满载）：3.0.16 55.3 / 3.0.17 58.9 / 3.0.18 62.6 / **3.0.19 65.7 ms** —— 老问题，本版只 +5%。

## 5. 装完之后的分支决策

| 现象 | 该做什么 |
|---|---|
| 清晰推上去后立体感够、屏闪能接受 | **收工**，这就是终版 |
| 立体感还不够 | 先切「清晰磨皮」并把「清晰」推到 60~80（边缘对比可到 +22.8%）；再不够就调 `kTexModes[1].edge`（3.0.19 现值 **500**，有效增益 2.95×）。历史「到 512 会发脆」那条结论已在 3.0.19 复核时修正：镜框区域过冲>4级像素占比从 300 抬到 500 只 +3.2% |
| 磨皮质感好，但静止时颗粒沸腾/屏闪明显 | 先试「清晰磨皮」（它把平坦区细频压掉，实测闪动 −3.8%）；仍不够再改 `kDetailVelStill` 0.15 → 0.05 编 3.0.18。**不要**动 `kBlendBetaStill` |
| 觉得不够干净 | 开「祛斑痘」，但要接受闪动 +55.8% |
| 觉得磨皮把脸磨平了、像塑料 | 检查「磨皮模式」是否停在「人像磨皮」，先切「清晰磨皮」看差异；再不行降低「磨皮」滑块 |
