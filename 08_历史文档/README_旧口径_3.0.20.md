## 一、它是什么

一套 OBS Studio 美颜插件，分两个模块，版本独立编号：

| 模块 | 作用 | 装机位置 |
|---|---|---|
| 滤镜 `obs-beauty.dll` | 出现在源滤镜列表里的「OBS美颜」，负责真正的像素处理 | `C:\Program Files\obs-studio\obs-plugins\64bit\` |
| UI `obs-beauty-ui.dll` | 在 OBS 顶层菜单加「美颜(&A)」，打开独立参数面板 | `C:\ProgramData\obs-studio\plugins\obs-beauty-ui\bin\64bit\` |

底层调用 FaceUnity NamaSDK（`fuai.dll` / `CNamaSDK.dll`，闭源），
SDK 运行时放在滤镜同级目录 `obs-plugins\64bit\obs-beauty\`（约 97 MB）。

## 二、快速开始

### 装机（三条路，按方便程度排）

**1. 安装包（最省事，带卸载）**

双击 `D:\插件\OBS美颜_Setup_v3.0.20.exe`，一路「下一步」。它会装好两个模块与 SDK，
并在注册表写入卸载项 —— 以后从开始菜单「OBS美颜」或控制面板「程序和功能」卸载。
只支持 OBS 的默认路径 `C:\Program Files\obs-studio`。

**2. 整合包脚本（不写注册表）**

1. 解压 `D:\插件\OBS美颜_v3.0.20_整合包.zip`；
2. 关闭 OBS（含托盘进程）；
3. 双击 `INSTALL.bat`，UAC 点「是」。脚本会备份旧 DLL、复制新 DLL、
   缺 SDK 时补 SDK、最后打印 md5 供核对。

### 只更新 UI 面板（开发用）

双击 `02_装机\install_ui_320.bat`，只替换 UI 模块，滤镜不动。

### 回滚

| 目的 | 操作 |
|---|---|
| 回滚两个模块到上一代 | 整合包内 `ROLLBACK.bat`（滤镜 3.0.18 / UI 3.0.19） |
| 卸载插件 | `02_装机\OBS美颜插件卸载.bat` |

回滚脚本同样自提权、拒绝在 OBS 运行时执行、装完打印 md5。

### 用法

1. 给摄像头源（或任意视频源）添加滤镜「OBS美颜」；
2. 调参有两条路：OBS 原生「滤镜属性」窗口，或顶层菜单「美颜 → 参数面板」；
3. 两处共用同一份设置，改哪边都即时生效。

## 三、面板（UI 3.0.20）

```
┌─ OBS美颜参数面板 ─────────────────────────┐
│ 作用对象 [ 视频采集设备 → OBS美颜  ▾ ] [刷新] │
│ 改动即时生效。                              │
│ ┌ 参数区（可滚动）──────────────────────┐ │
│ │ 磨皮模式 / 磨皮 / 清晰 / 美白 / 红润 …  │ │
│ │ ▶ 高级                                 │ │
│ └────────────────────────────────────────┘ │
│ v3.0.20  [恢复默认]              [关闭]     │
└────────────────────────────────────────────┘
```

- 默认宽度 **460 px**，一屏放得下，无横向滚动条；窗口尺寸仍可手动拉。
- 左下角灰字 `v3.0.20` 是面板版本，与菜单「美颜 → 关于」共用同一个编译期常量。
- 「高级」默认收起，展开后是 启用 / 旋转 / 识别模式 / 人物个数 / 镜像。
- 面板**不显示**「恢复默认 / 保存 preset / 读取 preset」这三个按钮（3.0.20 起隐藏），
  需要时在 OBS 原生「滤镜属性」窗口里用。
- 面板不订阅参数变化：在滤镜属性页改完，切回面板时才刷新。

## 四、参数速查

### 磨皮模式四档（3.0.19 实际值）

| 档位 | base | flat | edge | 观感 |
|---|---|---|---|---|
| 0 人像磨皮（默认） | 284 | 0 | 400 | 3.0.16 基线 + 结构区锐利化 |
| **1 清晰磨皮** | 256 | 256 | **500** | 平坦区细频压掉，结构区最锐（推荐） |
| 2 精细磨皮 | 200 | 200 | 300 | 整体收一档，平坦更干净 |
| 3 朦胧磨皮 | 140 | 0 | 0 | 细频整体压低，柔光镜观感 |

有效增益 = `base/256 × (1 + edge/256)`：人像 2.84 / 清晰 2.95 / 精细 1.70 / 朦胧 0.55。
**「锐化」为 0 时 edge 乘的是 0**，所以模式差异要靠「锐化」或「清晰」才体现得出来 ——
这也是 3.0.19 那处「锐化 = 0 时模式 1/2 仍差 ±1 级」的成因（`texModeNeedsBaseline` 兜底）。

### 常用调法

| 想要 | 怎么调 |
|---|---|
| 干净又立体 | 磨皮模式选「清晰磨皮」，磨皮 50~80，清晰推到 60~80 |
| 磨皮够但背景糊 | 检查「全局锐化」是否为 0；锐化 0 时背景逐字节不变是设计行为 |
| 静止时颗粒沸腾 | 先试「清晰磨皮」（平坦区闪动 −3.8%），仍不够再考虑改 `kDetailVelStill` |
| 不够干净 | 开「祛斑痘」，代价是闪动明显上升（实测 +55.8%） |
| 脸被磨平像塑料 | 别停在「人像磨皮」，切「清晰磨皮」；再降磨皮滑块 |

> 完整参数表与禁忌见 `HANDOVER_交接给下一个AI.md`；磨皮模式的推导与抗噪实验见
> `07_历史文档\OPTIMIZE_3.0.17_磨皮模式.md`。

## 五、重新编译

依赖：MSVC 14.51.36231（注意目录是 `Visual Studio\18`）+ Windows SDK 10.0.26100.0
+ Qt 6.8.3（只有 UI 模块需要）。

```
01_构建\build_manual.bat     -> 滤镜 obs-beauty.dll
01_构建\build-ui_320.bat     -> 面板 obs-beauty-ui.dll
```

两个脚本都手工设置 `INCLUDE` / `LIB` / `PATH`，绕开 `vcvars64.bat`
（沙箱拦 `reg.exe`，`vcvars64.bat` 跑不起来）。改版本号只需改源码里的
`NAMA_BUILD_STR`（`nama_engine.h`）或 `BEAUTY_UI_VERSION`（`obs-beauty-ui.cpp`），
不用改脚本。

## 七、已知限制（不影响正常使用）

- 面板只显示面板版本，不显示滤镜版本 —— UI 在编译期无法知道运行时装的是哪个滤镜。
- 滤镜属性页里那个「恢复默认」按钮点击无效（OBS 传参与滤镜回调契约不匹配，滤镜侧既有缺陷）；
  面板底部那个「恢复默认」是面板自己实现的，可用。
- 滑块拖到 99 会回跳 10（端点吸附未实现）。
- 遮脸 / 木色背景场景下肤色掩码可能错位，此时磨皮效果会打空（P0 待办，量化证据见 INDEX §4）。

待办清单与性能基线见 `00_先读我_INDEX.md` §4。
