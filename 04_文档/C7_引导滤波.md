# C7 · 引导滤波（做了，但 CPU 上不划算）

> 2026-10-28 · 这是按用户「代价最大的最后做」的排序里最后一件大件。
> **结论：技术上成功（消除了阶梯效应），但性能不达标，默认关闭。**

## 0. 结论

| 指标 | 双边迭代（现用） | 引导滤波 | 判断 |
|---|---|---|---|
| **阶梯效应**（「小幅度高频」保留率） | **106.0%**（磨皮在造新纹理） | **99.7%**（不造新纹理） | ✅ 引导滤波胜 |
| 低频结构保留 | 99.7% | 98.1%（r=8/eps=200） | ⚠️ 略差 |
| 大幅度（五官轮廓）保留 | 99.1% | 96.6% | ⚠️ 略差 |
| 磨皮量（同档位） | 1.347 | 2.307 | 引导磨得更狠 |
| **1080p 纯磨皮帧** | **21.41 ms** | **31.41 ~ 31.92 ms** | ❌ 超预算 |

**1080p 31.9 ms 已经顶到 33 ms 的天花板**（还没算插件层 stagesurface 往返）。
所以引导滤波虽好，当前实现下不能当默认。代码保留，用环境变量开启。

## 1. 为什么它能消除阶梯效应

引导滤波的输出是**局部线性**的：

```
q = mean_a · I + mean_b
a = cov(I,p) / (var(I) + eps)
```

- 平坦区：`var(I)` 小 → `a ≈ 1` → `q ≈ I`（平滑）
- 边缘处：`var(I)` 大 → `a ≈ 0` → `q ≈ mean_b`（不平滑）

关键差别在**输出是连续函数**，而不是"对邻域做加权平均"。双边迭代会把平坦区
压成一个个平台，平台之间必然出现台阶；引导滤波的 `a`、`b` 在空间上也是平滑的
（它们本身又经过一次盒式滤波），所以没有台阶。

实测印证：「小幅度高频」保留率

- 双边迭代：**106.0%** —— 磨完反而比原图多了纹理，这就是阶梯
- 引导滤波：**99.7%** —— 与原图持平

## 2. 为什么这么慢

理论是 O(1)/像素（盒式滤波与半径无关），但**常数因子很大**：

每个颜色通道要 4 次二维盒式滤波（mean_p、mean(I·p)、mean_a、mean_b），
每次二维盒式 = 水平 + 垂直两个 pass：

```
3 通道 × 4 次 × 2 pass = 24 遍全 ROI 遍历
```

1080p 的 ROI 约 25 万像素（外扩 r=12 后更大），24 遍就是 600 万次 float 读写，
加上 11 个 float 缓冲的内存带宽，实测 31.9 ms。

对比双边迭代：2 次迭代 × 25 次采样 = 50 次邻域读取，但都在 L1/L2 里，反而快。

**优化方向（都还没做）**：

| 手段 | 预期收益 |
|---|---|
| 在 1/2 或 1/4 分辨率的 ROI 上做引导滤波，再上采样 | 4~16 倍（低频本来就是低频） |
| 用整数定点代替 float，减少内存带宽 | 约 1.5~2 倍 |
| 合并 mean_p / mean(I·p) 的 pass | 约 1.3 倍 |
| 上 GPU | 彻底解决 |

第二条 + 第一条一起做，1080p 有望压到 8~10 ms —— 那才值得当默认。

## 3. 现在的开关

```bash
BEAUTY_LOW_MODE=0   # 默认：双边迭代
BEAUTY_LOW_MODE=1   # 引导滤波
BEAUTY_GUIDE_R=12   # 引导滤波半径
BEAUTY_GUIDE_EPS=400
```

导出：`BeautyCoreSetGuide(mode, radius, eps)`。

`verify_roi.py` 三档仍全部 PASS（maxdiff=0），说明默认路径没被影响。

## 4. 参数扫描结果

（640×394、磨皮 100 档、`face_src`）

| 配置 | 磨皮量 | 低频保留 | 小幅度 | 中幅度 | 大幅度 |
|---|---|---|---|---|---|
| 双边 iters=2 | 1.347 | 99.7% | **106.0%** | 96.7% | 99.1% |
| 引导 r=8 eps=200 | 2.307 | 98.1% | **99.7%** | 88.7% | 96.6% |
| 引导 r=12 eps=400 | 3.262 | 96.0% | 99.3% | 84.1% | 94.5% |
| 引导 r=16 eps=400 | 3.407 | 95.0% | 87.5% | 84.5% | 94.6% |
| 引导 r=16 eps=800 | 4.204 | 93.8% | 97.9% | 80.7% | 93.6% |

规律：`radius` 和 `eps` 越大 → 磨得越狠、低频和大幅度掉得越多。
`r=8/eps=200` 是最保守的一组，也是唯一「低频还在 98% 以上」的。

> 注意 `r=16 eps=400` 的小幅度掉到 87.5% —— 它把细纹理也当瑕疵磨了，反而回到
> "糊"的老问题。**半径不是越大越好。**

## 5. 事实 vs 推测

**实测**：上表全部数字、两种方式的耗时、`verify_roi.py` 三档 maxdiff=0。

**未验证**：
- 引导滤波路径的 ROI 等价性没有单独做过对比（默认路径不受影响）
- 「小幅度 99.7% 在观感上就等于没有塑料感」—— 指标对了，但没做人眼确认
- 降分辨率 + 定点的优化能压到多少，是估算，没实施
- eps 的物理含义（约等于「多少灰阶的差异算边缘」）是按公式推的，没标定
